# Saorsa 安全说明

## 供应商 API Key

* 管理员在控制台录入后立即以 AES-256-GCM 加密存储（每个 Key 独立随机 nonce，密文与 Key 行 id 绑定）；主密钥只来自环境变量 `SAORSA_MASTER_KEYS`，不进数据库、不进 Git。支持多版本主密钥轮换（`SAORSA_MASTER_KEY_ACTIVE` + `/api/admin/credentials/reencrypt`）。
* 任何接口只返回后 4 位遮罩与指纹；撤销时销毁密文。创建、轮换、停用、撤销均写入审计日志。
* 成员、浏览器、OpenCode 配置、Launcher 都拿不到供应商 Key；网关在服务端解密后直接调用上游。
* 测试只使用标注 TEST 的假凭据（`mock-upstream-test-key-not-a-secret`）。

## Saorsa 凭据

| 凭据 | 用途 | 生命周期 | 存放 |
|---|---|---|---|
| 网页会话 | 控制台 | 默认 12 小时；HttpOnly + SameSite Cookie；写操作需 CSRF 头 | 浏览器 Cookie |
| OpenCode 令牌 | OpenCode 1.x well-known 登录 | 使用时滑动续期，30 天未用过期 | OpenCode 自身认证存储 |
| Launcher 会话 | 一台设备上的 Launcher | 30 天 | OS 凭据存储 |
| 工具子令牌 | Launcher 每次启动工具 | 默认 12 小时，不续期；随 Launcher 会话撤销 | 仅子进程环境变量 |
| 工具 Key | IDE 类工具设置中填写 | 使用时滑动续期；可在“个人设置”撤销 | 成员填入的工具设置 |

所有令牌在数据库中只存 SHA-256 哈希；每个客户端令牌都绑定**一个项目组与一个工具**，网关从服务端会话读取成员、项目组与工具，从不信任客户端传入的 user/project/tool。修改密码、禁用成员、移出项目组、管理员强制下线会立即使其失效；单设备登录开启时，同一通道在新设备登录会撤销旧设备会话。

## 网关授权链

每个请求依次校验：令牌有效 → 会话类型为客户端 → 项目组 active 且成员仍在组内 → **工具已被该项目组授权** → 模型对项目组授权且允许该工具 → 协议匹配 → **模型能力满足请求**（工具调用、流式、图片、结构化输出）→ 价格已配置 → Key 分配（独占模式）→ 限流 → 预算预留 → 凭据泄露检测 → 上游调用。被拒绝的请求在预留预算与调用上游之前返回，错误带 `x-should-retry` 以免工具无限重试。

## 本地 Launcher

见 `docs/launcher.md`：不执行服务器下发的命令；每个动作需成员同意；只走官方安装来源；凭据存 OS 凭据存储；子令牌只在进程环境中；只修改它自己负责的那一项配置并可还原；日志脱敏；不上传源码或路径。

## 隐私与审计

* 默认不保存对话全文，只保存风险命中的脱敏片段与哈希指纹；保留期可配置（请求 180 天、风险 365 天默认）。
* 风险提示（项目无关、高频、费用突增、频繁切换、凭据泄露）只是复核线索，AI 分类结果不作为违规认定；成员可申诉，管理员访问风险详情会被审计。
* 成员使用告知需在连接客户端前确认，版本变更后需重新确认。

## 已知绕过风险（如实）

* Saorsa 只能统计和管控**经过网关**的调用。成员使用个人 Key、未纳管的工具，或在 Cursor/Copilot/JetBrains/TRAE/Qoder 中使用厂商自带模型与补全时，流量不经 Saorsa。
* “受管客户端仅允许企业模型”只对已连接 Saorsa 的 OpenCode 生效；它不能阻止成员另装一个不连接 Saorsa 的工具。
* 强制管控需要受控终端（MDM 下发托管配置，例如 Claude Code 的 `allowedProviders`）与网络出口策略（只放行 Saorsa 网关，拦截各供应商 API 域名）配合，单靠 Launcher 或插件无法做到绝对防绕过。
* Cursor 的 BYOK 请求由 Cursor 云端转发，需要把网关暴露到公网，并接受 Cursor 能看到请求内容这一事实。
