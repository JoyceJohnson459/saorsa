# Saorsa brand assets

Original geometric mark: a single data-flow trace that forms an "S" between an open source node (top) and a
filled destination node (bottom). Flat colors only, no gradients or glow.

| File | Use |
|---|---|
| `saorsa-icon-dark.svg` | Icon on dark backgrounds (`#55F68A` on `#080B0A`) |
| `saorsa-icon-light.svg` | Icon on light backgrounds (`#16A34A` on white) |
| `saorsa-logo-horizontal-dark.svg` / `-light.svg` | Horizontal logo with wordmark and tagline |
| `favicon.svg` | Browser tab icon (heavier stroke for 16px) |
| `saorsa-app-icon.svg`, `saorsa-app-icon-512.png` | Launcher / application icon |

Tokens: background `#080B0A`, surface `#101512`, card `#151C18`, accent `#55F68A`, accent dark `#16A34A`,
text `#F5F7F5`, secondary text `#8C9A90`, border `#253128`, error `#EF6464`, warning `#F5B84B`.
